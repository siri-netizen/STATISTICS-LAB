Binomial Distribution

Models the number of successes in a fixed number of independent trials, each with the same probability of success.

X ~ Binomial(n, p)

Poisson Distribution

Models the number of times an event occurs in a fixed interval of time or space.

X ~ Poisson(λ)

Geometric Distribution

Models the trial number on which the first success occurs in repeated independent trials.

X ~ Geometric(p), X = 1, 2, 3, ...
